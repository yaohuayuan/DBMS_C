\chapter*{使用说明}
本指导书面向数据库课程实践、计算机专业低年级学生以及 DBMS\_C 项目阅读者。它围绕当前仓库中的真实 C 源码、测试入口、Trace 输出和图表组织实验内容，帮助读者逐步理解一个轻量化教学型 DBMS 原型的内部机制。

本指导书不是毕业论文，也不是工业级数据库手册。后续章节将遵循“先补充或确认真实 CTest，再撰写章节正文”的方式逐章完善；本轮仅完整整理第0章，并为第1章到第12章保留统一占位结构。
